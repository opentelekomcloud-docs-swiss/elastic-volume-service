Updating Snapshot Information
=============================

Function
--------

This API is used to update information about a snapshot.

Calling Method
--------------

For details, see :ref:`Calling APIs <evs_04_0009>`.

URI
---

PUT /v5/{project_id}/snapshots/{snapshot_id}

.. table:: **Table 1** URI parameters

   +-----------------+-----------------+-----------------+---------------------------------------------------------------+
   | Parameter       | Mandatory       | Type            | Description                                                   |
   +=================+=================+=================+===============================================================+
   | project_id      | Yes             | String          | The project ID.                                               |
   |                 |                 |                 |                                                               |
   |                 |                 |                 | For details, see :ref:`Obtaining a Project ID <evs_04_0046>`. |
   +-----------------+-----------------+-----------------+---------------------------------------------------------------+
   | snapshot_id     | Yes             | String          | The snapshot ID.                                              |
   +-----------------+-----------------+-----------------+---------------------------------------------------------------+

Example Requests
----------------

.. code-block:: text

   PUT https://{endpoint}/v5/{project_id}/snapshots/{snapshot_id}

   {
     "snapshot" : {
       "name" : "snap-001",
       "description" : "Daily backup",
       "instant_access" : false
     }
   }
