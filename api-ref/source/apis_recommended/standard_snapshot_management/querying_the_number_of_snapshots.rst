Querying the Number of Snapshots
================================

Function
--------

This API is used to query the number of snapshots.

Calling Method
--------------

For details, see :ref:`Calling APIs <evs_04_0009>`.

URI
---

GET /v5/{project_id}/snapshots/count

.. table:: **Table 1** URI parameter

   +-----------------+-----------------+-----------------+---------------------------------------------------------------+
   | Parameter       | Mandatory       | Type            | Description                                                   |
   +=================+=================+=================+===============================================================+
   | project_id      | Yes             | String          | The project ID.                                               |
   |                 |                 |                 |                                                               |
   |                 |                 |                 | For details, see :ref:`Obtaining a Project ID <evs_04_0046>`. |
   +-----------------+-----------------+-----------------+---------------------------------------------------------------+

.. table:: **Table 2** Query parameters

   +-----------------------+-----------+--------+---------------------------------------------------------------------------------+
   | Parameter             | Mandatory | Type   | Description                                                                     |
   +=======================+===========+========+=================================================================================+
   | volume_id             | No        | String | The ID of the snapshot's source disk.                                           |
   +-----------------------+-----------+--------+---------------------------------------------------------------------------------+
   | availability_zone     | No        | String | The AZ of the snapshot's source disk.                                           |
   +-----------------------+-----------+--------+---------------------------------------------------------------------------------+
   | name                  | No        | String | The snapshot name. It can contain a maximum of 255 characters.                  |
   +-----------------------+-----------+--------+---------------------------------------------------------------------------------+
   | status                | No        | String | The snapshot status. For details, see :ref:`EVS Snapshot Status <evs_04_0041>`. |
   +-----------------------+-----------+--------+---------------------------------------------------------------------------------+
   | id                    | No        | String | The snapshot ID.                                                                |
   +-----------------------+-----------+--------+---------------------------------------------------------------------------------+
   | snapshot_type         | No        | String | The snapshot creation source.                                                   |
   +-----------------------+-----------+--------+---------------------------------------------------------------------------------+
   | enterprise_project_id | No        | String | The ID of the enterprise project to which the snapshot belongs.                 |
   +-----------------------+-----------+--------+---------------------------------------------------------------------------------+
   | tag_key               | No        | String | The snapshot tag key.                                                           |
   +-----------------------+-----------+--------+---------------------------------------------------------------------------------+
   | tags                  | No        | String | The snapshot key-value pairs, for example, {"key1":"value1"}.                   |
   +-----------------------+-----------+--------+---------------------------------------------------------------------------------+
   | snapshot_chain_id     | No        | String | The snapshot chain ID.                                                          |
   +-----------------------+-----------+--------+---------------------------------------------------------------------------------+
