Querying Details About All Snapshots
====================================

Function
--------

This API is used to query details about all snapshots.

Calling Method
--------------

For details, see :ref:`Calling APIs <evs_04_0009>`.

URI
---

GET /v5/{project_id}/snapshots/detail

.. table:: **Table 1** URI parameter

   +-----------------+-----------------+-----------------+---------------------------------------------------------------+
   | Parameter       | Mandatory       | Type            | Description                                                   |
   +=================+=================+=================+===============================================================+
   | project_id      | Yes             | String          | The project ID.                                               |

   |                 |                 |                 | For details, see :ref:`Obtaining a Project ID <evs_04_0046>`. |
