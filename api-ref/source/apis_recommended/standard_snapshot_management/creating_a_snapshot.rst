Creating a Snapshot
===================

Function
--------

This API is used to create a standard snapshot.

URI
---

POST /v5/{project_id}/snapshots

.. table:: **Table 1** URI parameter

   +-----------------+-----------------+-----------------+---------------------------------------------------------------+
   | Parameter       | Mandatory       | Type            | Description                                                   |
   +=================+=================+=================+===============================================================+
   | project_id      | Yes             | String          | The project ID.                                               |
   |                 |                 |                 |                                                               |
   |                 |                 |                 | For details, see :ref:`Obtaining a Project ID <evs_04_0046>`. |
   +-----------------+-----------------+-----------------+---------------------------------------------------------------+

Request Parameters
------------------

.. table:: **Table 2** Request header parameter

   +-----------------+-----------------+-----------------+---------------------------------------------------------------------------------------------------------------------------------------------------+
   | Parameter       | Mandatory       | Type            | Description                                                                                                                                       |
   +=================+=================+=================+===================================================================================================================================================+
   | X-Auth-Token    | No              | String          | The user token.                                                                                                                                   |
   |                 |                 |                 |                                                                                                                                                   |
   |                 |                 |                 | It can be obtained by calling the IAM API used to obtain a user token. The value of **X-Subject-Token** in the response header is the user token. |
   +-----------------+-----------------+-----------------+---------------------------------------------------------------------------------------------------------------------------------------------------+

.. table:: **Table 3** Request body parameter

   +-----------+-----------+----------------------------------------------------------------------------------------------------------------------+-------------+
   | Parameter | Mandatory | Type                                                                                                                 | Description |
   +===========+===========+======================================================================================================================+=============+
   | snapshot  | Yes       | :ref:`CreateStandardSnapshot <createsnapshotv5__en-us_topic_0000002229564386_request_createstandardsnapshot>` object | ``-``       |
   +-----------+-----------+----------------------------------------------------------------------------------------------------------------------+-------------+

.. _createsnapshotv5__en-us_topic_0000002229564386_request_createstandardsnapshot:

.. table:: **Table 4** CreateStandardSnapshot

   +----------------+-----------+--------------------+-----------------------------------------------------------------------------------------------------------------+
   | Parameter      | Mandatory | Type               | Description                                                                                                     |
   +================+===========+====================+=================================================================================================================+
   | volume_id      | Yes       | String             | The disk ID.                                                                                                    |
   +----------------+-----------+--------------------+-----------------------------------------------------------------------------------------------------------------+
   | name           | No        | String             | The snapshot name. It can contain a maximum of 64 characters.                                                   |
   +----------------+-----------+--------------------+-----------------------------------------------------------------------------------------------------------------+
   | description    | No        | String             | The snapshot description. It can contain a maximum of 85 characters.                                            |
   +----------------+-----------+--------------------+-----------------------------------------------------------------------------------------------------------------+
   | tags           | No        | Map<String,String> | The snapshot tags.                                                                                              |
   +----------------+-----------+--------------------+-----------------------------------------------------------------------------------------------------------------+
   | instant_access | No        | Boolean            | Whether to enable Instant Snapshot Restore. The default value is **false**, indicating not enable the function. |
   +----------------+-----------+--------------------+-----------------------------------------------------------------------------------------------------------------+
   | incremental    | No        | Boolean            | Whether to create an incremental snapshot.                                                                      |
   +----------------+-----------+--------------------+-----------------------------------------------------------------------------------------------------------------+

Example Requests
----------------

.. code-block:: text

   POST https://{endpoint}/v5/{project_id}/snapshots

   {
     "snapshot" : {
       "volume_id" : "2c194dde-7de5-4529-a141-49f48181f411",
       "name" : "test_name",
       "description" : "test description"
     }
   }

Example Responses
-----------------

**Status code: 202**

Accepted

.. code-block::

   {
     "job_id" : "ee62a0c1e79c4e11be5adc17a49f69ef",
     "snapshot_id" : "bb02c803-55ac-4e84-9c80-60d352199d7d"
   }

**Status code: 400**

Bad Request

.. code-block::

   {
     "error" : {
       "code" : "string",
       "message" : "string"
     }
   }
